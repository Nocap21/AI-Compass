# AI Compass

AI Compass is a responsive web platform that helps users discover, explore, compare, and bookmark AI tools based on their needs.

## Features

* Explore information about 54 AI tools
* Search AI tools by name, category, and keywords
* Filter tools by category, pricing, platform, skill level, and industry
* View detailed information about each AI tool
* Bookmark favorite tools using Local Storage
* Compare two AI tools
* View recently visited tools
* Dark mode support
* Responsive design for desktop, tablet, and mobile
* Official AI-tool logos and website links

## Technologies Used

* HTML5
* CSS3
* JavaScript
* JSON
* Local Storage

## How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in a browser.
4. Explore the AI Compass platform.
