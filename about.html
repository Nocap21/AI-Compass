OUR STORY

Built to help you find your bearing.

AI Compass is a directory of the AI tools people actually use — organized, rated, and comparable in one place, so choosing the right tool takes minutes instead of an afternoon of open tabs.

000°

Project Overview

A searchable, filterable catalog of AI tools across 14 categories, with detail pages, side-by-side comparisons, and a personal bookmarks list — all running entirely in the browser.

120°

Purpose

New AI tools launch every week. AI Compass exists to cut through that noise with honest pros/cons, real pricing, and quick comparisons.

240°

Future Improvements

User reviews, a submit-a-tool form, saved comparison history, and a public API for the dataset are all on the roadmap.

Technologies Used

HTML5 CSS3 Vanilla JavaScript (ES6) JSON Local Storage

Roadmap

Now — Core directory, search, filters, compare, bookmarks.
